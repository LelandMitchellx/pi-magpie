# pi-magpie 领域术语表 (GLOSSARY.md)

本词汇表定义 pi-magpie 集成上下文中的通用统一语言，消除网关、代理 Harness 与扩展开发之间的术语歧义。

## 核心语言定义

**网关 (Gateway)**:
在本地后台运行的模型路由服务，默认监听 `127.0.0.1:8317`（支持 `MAGPIE_ADDR` 环境变量覆盖），提供兼容 OpenAI/Anthropic/Gemini 协议的模型转发与配额统计。
_避免使用_: 代理 (Proxy), 后端服务, 中继 (Relay)

**统一单进程服务 (Unified Service Process)**:
由插件在后台自动拉起并守护的单个综合进程 (`magpie web --no-open`)，在同一进程内同时提供嵌入式网关（端口 8317）与 Web 管理控制台（端口 3430），实现资源减半与状态原子一致。
_避免使用_: 双进程, 独立后台, 拆分守护

**动态随机 Web 密钥 (Ephemeral Random Web Key)**:
每次启动统一服务时在内存中动态生成的 64 字符密码学安全随机 Token，注入 `MAGPIE_WEB_KEY`。仅保存在内存中，重启后自动安全轮换，替代旧版静态固定密码。
_避免使用_: 固定密钥, 静态 Token, 登录密码

**供应商 (Provider)**:
集成接入 Magpie 的上游 AI 基础设施或服务方（如 Antigravity、DeepSeek、Codex 等）。
_避免使用_: 厂商, 第三方, 后端

**双模架构 (Dual-Mode)**:
单仓库统一代码同时导出 Pi 宿主原生扩展（Extension）与独立 Stdio MCP 服务端二进制的可复用设计模式。
_避免使用_: 混合体, 二合一, 多目标

**二进制探测优先级 (Binary Precedence)**:
按固定顺序在插件私有目录、环境变量、系统 PATH、系统常见目录中查找 `magpie` 可执行文件，并在全未命中时触发自动下载的分级解析机制。
_避免使用_: 路径查找, 文件搜索

**静默自愈 (Auto-Heal)**:
在 Pi 会话启动或 MCP 初始化时，后台静默执行健康检查并在离线时自动唤醒统一服务，全程不阻塞 UI 渲染和用户交互的守护机制。
_避免使用_: 自动重启, 兜底脚本

**按需 Web 控制台 (On-Demand Web Dashboard)**:
在用户需要管理界面时唤起的浏览器页面 (`http://127.0.0.1:3430/?k=...`)，携带当前运行时的动态随机安全密钥实现免密登录。
_避免使用_: 网页后台, 前端进程
