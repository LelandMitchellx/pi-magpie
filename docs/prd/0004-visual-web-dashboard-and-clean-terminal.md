# PRD 0004: 交互延伸——Web 免密控制台与纯净终端

## 问题陈述

虽然 PRD 0001 提供了后台网关，但在实际使用中，开发者仍有管理模型、调整分流权重、配置 API 密钥和查看 Token 消耗的现实需求。然而：
1. **终端字符界面的局限性**：终端表格和命令行极不适合复杂账单图表与多模型层级配置的展现；
2. **AI 工具上下文污染**：如果在 Pi 中注册十几个模型管理相关的 AI Tools，会大量挤占 LLM 宝贵的 System Prompt 窗口与上下文配额，干扰 Agent 的代码理解能力；
3. **安全与免密登录断层**：Magpie Web 控制台默认具备鉴权保护，若用户打开控制台需要到处翻找配置文件复制密码，体验极其割裂。

## 解决方案

坚决贯彻“零 AI Tool 上下文污染”与“视觉交互回归浏览器”的设计哲学。在 Pi 终端内仅保留一条极简 `/magpie` 命令用于快速查验运行态；将复杂的模型与账单管理一键导流至 Magpie 自带的现代 Web 控制面板（`http://localhost:3430`）。通过动态生成与注入控制台安全密钥，提供带 `?k=<key>` 的免密直达链接，实现两秒内无缝可视化操作。

## 用户故事

1. 作为一名在终端编写代码的开发者，我希望 Agent 上下文中不包含任何多余的模型管理 AI Tools，以便于将 100% 的上下文 Token 留给我的业务代码。
2. 作为一名需要查看 Token 消耗或调整模型的开发者，我希望通过敲一个极简的 `/magpie` 命令，就能看到网关运行状态以及一键可点击的 Web 控制台链接。
3. 作为一名访问 Web 控制面板的用户，我希望控制台链接自动附带已授权的密钥参数，以便于我无需手动翻找配置或反复复制粘贴密码。
4. 作为一名想要固定密钥的开发者，我希望扩展能够识别 `MAGPIE_WEB_KEY` 环境变量，以便于我在不同机器环境中保持一致的管理密码。
5. 作为一名在多会话并发环境下的开发者，我希望后续接入的 Pi 会话能够共享同一套 Web 控制面板地址与鉴权密钥。

## 实现决策

1. **绝对零 AI 上下文污染**：
   - 严禁调用 `pi.registerTool` 注册任何面向 LLM 的模型管理工具；
   - 所有模型管理操作完全由人类开发者在图形浏览器中完成，Agent 只专注于代码生成与修改。

2. **单一 Slash 指令设计**：
   - 仅注册唯一的 `/magpie` Slash 命令；
   - 执行后整合输出：网关地址、健康状态、Web 控制面板免密直达链接、密钥明文、进程归属、多会话集群状态与当前 Pi 绑定的模型名称。

3. **动态密钥注入与免密直达**：
   - 在首次拉起 Web 进程时，自动利用加密随机数生成 32 字节高强度密钥；
   - 通过环境变量 `MAGPIE_WEB_KEY` 注入网关进程，并持久化到托管元数据中供后续 Pi 会话共享；
   - 生成的控制台访问链接格式统一为 `http://127.0.0.1:3430/?k=<key>`，浏览器一键点击即可完成免密鉴权。

## 测试决策

1. **测试边界**：
   - 验证 URL 构造器（`getWebUrl`）与密钥获取（`getWebKey`）在不同环境变量与元数据配置下的输出。
2. **测试重点**：
   - 验证当未指定环境变量时，随机密钥的长度与格式符合要求；
   - 验证当指定 `MAGPIE_WEB_KEY` 时优先采用该环境变量；
   - 验证生成的链接包含正确的端口与免密查询参数。

## 范围外声明

1. 在终端内构建全套 TUI 模型配置表单（复杂配置坚决交给浏览器）。
2. 接管 Magpie Web 控制台内部的前端 UI 或增加定制页面。

## 补充备忘

- 本需求是 PRD 0001 在人机交互维度的优雅延伸。终端保持最纯粹的极简风格，图形交互留给表现力更强的浏览器，各得其所。
