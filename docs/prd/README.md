# pi-magpie 产品需求演进体系 (PRDs)

> *"所有的需求都是一张网，而这张网唯一的引力中心，是 PRD 0001 的核心初衷。"*

本项目严格遵循 **Matt Pocock 标准工程规范**，采用分立递进的演进式 PRD 体系。所有 PRD 统一遵循以下 7 大标准章节：
1. **问题陈述 (Problem Statement)**：从用户视角出发的真实痛点；
2. **解决方案 (Solution)**：从用户视角出发的破局方案；
3. **用户故事 (User Stories)**：标准编号的 `作为一名...我希望...以便于...` 列表；
4. **实现决策 (Implementation Decisions)**：不写死易过期代码，聚焦模块契约与高层决策；
5. **测试决策 (Testing Decisions)**：聚焦黑盒行为与测试边界 (Seams)；
6. **范围外声明 (Out of Scope)**：明确边界，坚决防范需求蔓延；
7. **补充备忘 (Further Notes)**：关键设计思考与演进备忘。
